额度泡泡使用帮助

额度泡泡是独立开发的 Codex 配额查看工具。这里介绍官方订阅模式的安装、额度查看和会话同步；具体字段以当前账号实际返回的数据为准。

安装5 小时与每周额度恢复与重置会话同步桌面状态

1. 安装 macOS 或 Windows 版

macOS 13 及以上：从官网下载 DMG，打开后将 Quota Bubble.app 拖入 Applications（应用程序），再从“应用程序”中启动。支持 Apple 芯片与 Intel。

Windows 10 及以上：从官网下载 Setup 安装器，运行并按向导完成安装，然后从桌面快捷方式启动。

请先在本机登录 Codex 官方订阅账号。额度泡泡使用本机已有的 Codex 登录状态读取该账号配额，不需要在官网提交账号凭据。

前往官网下载

2. 查看 5 小时与每周剩余额度

打开额度泡泡，查看对应配额窗口的剩余百分比和进度条。若账号提供 5 小时限制，会同时显示该窗口；没有该限制时，界面保留可用的每周配额信息。

这些读数来自当前账号，不是所有 Codex 订阅都拥有相同额度。菜单栏或托盘百分比优先使用 5 小时配额，没有时使用每周配额。

3. 区分额度恢复时间与手动重置

恢复时间：配额旁的倒计时和日期表示该额度窗口何时恢复。它不是订阅到期时间，两个日期请分别查看。

手动重置：仅当账号支持并存在可用重置额度时，才按界面提供的操作使用。手动重置会消耗对应额度，请先阅读确认提示；不能将此功能理解为所有订阅均可无限重置。

4. 使用会话同步

先保存正在进行的工作，再点击窗口中的 会话同步。进度窗口依次显示环境检查、工具准备、会话迁移和重启结果。按当前提示等待完成。

同步流程需要关闭并重新打开 Codex。完成后查看明确的成功或失败结果；如果失败，请保留错误提示，不要把启动请求已发出当作迁移成功。

5. 查看桌面与运行状态

窗口也提供网速、估算带宽、可用存储、内存与诊断入口。实时网速反映当前流量，估算带宽受线路与测量环境影响，不等于宽带套餐上限。

底部数量表示匿名活跃客户端数，不是经过验证的在线人数；宣传预览中的数量为示例。版本号显示在窗口底部，可用于确认当前安装版本。
