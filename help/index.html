Maple AI

Maple AI 是适用于 macOS 和 Windows 的 Codex 桌面助手。

安装 Maple AI

macOS 13+ 适用于 macOS 13 及以上，支持 Apple 芯片和 Intel。打开 DMG，然后将应用拖入“应用程序”。

Windows 10+ 适用于 Windows 10 及以上。运行 Setup 安装器，按向导完成安装。

了解 5.0 工作台

  • 仪表盘 查看账户余额、今日 Token 和请求数，跟踪近期费用与模型用量。
  • API 密钥与模型费率 管理与选择 API 密钥和分组，分别查看 Maple AI 与 OpenAI 的模型费率。
  • 兑换 在工作台输入兑换码，查看兑换结果与账户余额。
  • 设置 在五种界面风格之间切换，设置显示语言和各风格的声音。

工具箱

工具箱同步或应用语言包时，可能会关闭并重新打开 Codex。请先保存工作，并等待进度提示完成。

故障排查

检查网络连接、资源使用情况、CC Switch、Maple AI 和 Node.js。调整环境后，可重新检查。
