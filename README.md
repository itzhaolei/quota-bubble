## 5.0 工作区预览

- 在仪表盘查看用量、请求和今日 Token。
- 管理 API 密钥并查看模型费率。兑换页单独处理兑换码。
- 在工具箱同步 Codex 会话和模型，或安装简体中文语言。同步前请保存工作，Codex 会关闭并重新打开。
- 在诊断页查看网络和设备资源，在设置中调整语言和界面风格。

上述功能对应 [5.0 界面预览](https://codex.maple.xin/#interface)。安装包以[下载区](https://codex.maple.xin/#platformDownloads)标明的公开版本为准。

## 安装

1. 从[官网](https://codex.maple.xin/)下载适合当前系统的安装器，也可在[最新版本](https://github.com/itzhaolei/quota-bubble/releases/latest)中选择。
2. **macOS 13 及以上**（Apple 芯片或 Intel）：打开 DMG，将其中的应用拖入 `Applications（应用程序）`，然后启动。
3. **Windows 10 及以上**：运行 Setup 安装向导，完成后从桌面快捷方式启动。
4. 启动 Maple AI 后按应用提示完成配置。详细步骤见[使用帮助](https://codex.maple.xin/help/)。

Maple AI 为独立开发的工具，非 OpenAI 官方产品。本仓库提供官网文件与桌面安装器发行，应用源代码不在此公开。正式产品入口为上述官网与使用帮助。

## English

**Maple AI is an independently developed desktop companion for Codex on macOS and Windows.**

[Website and downloads](https://codex.maple.xin/en/) · [User guide (Chinese)](https://codex.maple.xin/help/) · [Latest installers](https://github.com/itzhaolei/quota-bubble/releases/latest)

### 5.0 workspace preview

- Check usage, requests and today's tokens in the dashboard.
- Manage API keys and view model rates. Use the dedicated redemption page for codes.
- Sync Codex sessions and models or install Simplified Chinese from the toolbox. Save work before syncing, since the operation closes and reopens Codex.
- Inspect network and device resources in Diagnostics. Choose the display language and appearance in Settings.

Explore the [5.0 interface preview](https://codex.maple.xin/en/#interface). The [download section](https://codex.maple.xin/en/#platformDownloads) lists the version available for installation.

### Installation

1. Download the installer for your system from the [website](https://codex.maple.xin/en/) or [latest release](https://github.com/itzhaolei/quota-bubble/releases/latest).
2. **macOS 13 or later**, on Apple silicon or Intel: open the DMG, drag the app into `Applications`, then launch it.
3. **Windows 10 or later**: run the Setup wizard, then launch the app from its desktop shortcut.
4. Launch Maple AI and follow the setup prompts. See the [user guide (Chinese)](https://codex.maple.xin/help/) for details.

Maple AI is an independent tool, not an official OpenAI product. This repository distributes the website and desktop installers; it does not publish the application source code. Use the website and user guide above as the official product entry points.
