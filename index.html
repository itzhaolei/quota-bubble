从看用量到排查问题

Maple AI 5.0 工作台设有六个页面，覆盖账户、Codex 操作和本机状态。

仪表盘

查看账户余额、今日 Token 和请求数，跟踪近期费用与模型用量。

API 密钥与模型费率

管理与选择 API 密钥和分组，分别查看 Maple AI 与 OpenAI 的模型费率。

兑换

在工作台输入兑换码，查看兑换结果与账户余额。

工具箱

同步 Codex 会话与模型，或应用简体中文语言包。界面显示每一步的进度。

故障排查

检查网络连通、带宽以及内存与存储使用情况，定位本机环境问题。

设置

在五种界面风格之间切换，设置显示语言和各风格的声音。
